### ⭐ Featured builds — run, don't just read

**1. [zero-trust-aws-ci-cd](https://github.com/iishanmakkar/zero-trust-aws-ci-cd) — push-to-prod in minutes**
Self-hosted Git + Jenkins → Docker build → private registry → isolated prod on EC2 + Nginx. Webhook-driven, SSH-key only, one-command compose stack.
`AWS • Jenkins • Docker • Forgejo • Nginx • Bash`

**2. [RetailSync](https://github.com/iishanmakkar/RetailSync) — fake store, real streaming problems**
Generator → Confluent Cloud Kafka → Spark Delta Bronze/Silver/Gold → SQL dashboards. NULLs, dupes, late + evolving schemas injected on purpose, cleaned in Silver.
`Kafka • Spark • Delta • Databricks SQL • Python`

**3. [Olympic-data-engineering](https://github.com/iishanmakkar/Olympic-data-engineering) — lakehouse analytics on Azure**
Raw CSVs → ADLS Gen2 → PySpark on Databricks → curated tables for BI. OAuth-secured, validated, repeatable notebook flow.
`Azure • ADLS Gen2 • Databricks • PySpark`

**4. [WinBatterySaver](https://github.com/iishanmakkar/WinBatterySaver) ★6 — shipped product, not a demo**
JavaFX tray app for Win10/11. EcoQoS throttling, health + drain analytics, MSI/portable releases, CI with 36 tests. Works on any OEM.
`Java • JavaFX • JNA • Gradle • WiX • GitHub Actions`
